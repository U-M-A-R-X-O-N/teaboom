# Teaboom — карточка товара «Ананасовый улун»

Тестовое задание: верхняя часть карточки товара (HTML5 + CSS + vanilla JS, без фреймворков).

## Запуск
Откройте `index.html` в браузере. Сборка не нужна. При желании: `npx serve .`

## Структура
- `index.html` — семантическая разметка (`article`, `figure`, `fieldset` с radio для фасовок, `section`)
- `css/style.css` — стили на CSS-переменных, Grid/Flexbox, брейкпоинт 767px
- `js/main.js` — данные фасовок и переключение (цена, старая цена, скидка, артикул, состояние)
- `assets/product.svg` — иллюстрация-заглушка; замените на фото с teaboom.ru

## Решения
- Фасовки — нативные radio-кнопки: клавиатура и скринридеры работают без доп. кода.
- Цена в `aria-live`, формат через `Intl.NumberFormat('ru-RU')`; процент скидки считается автоматически.
- Mobile (375px): колонка, фото 4:3, фасовки сеткой 2×2, кнопка на всю ширину.
- Уважается `prefers-reduced-motion`, виден `:focus-visible`.
